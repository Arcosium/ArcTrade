## ⚠ 2026-08-08 추가 검증 — **공적분 후보로 쓰기엔 무작위와 차이가 없다**

이 표를 넘긴 뒤에 "정말 무작위 쌍보다 나은가"를 표본 밖에서 확인했다. 결과는 아니었다.

창 A(2025-08-11~2026-02-07)에서 후보를 뽑고 완전히 분리된 창 B(2026-02-07~2026-08-06)에서
Engle-Granger 를 돌렸다. 대조군은 같은 종목 풀에서 **서로 다른 클러스터끼리** 무작위로 뽑은
같은 개수의 쌍이다 — 유동성·변동성 조건이 같아서 차이가 오직 "같은 클러스터인가" 하나만 남는다.

| | 후보(클러스터 내부) | 대조(무작위 교차) | |
|---|--:|--:|---|
| 검정 쌍 | 2,212 | 2,277 | |
| 원시 5% 기각률 | 15.2% | 13.0% | z=+2.12 |
| **BH 보정 기각률** | **1.63%** (36쌍) | **2.72%** (62쌍) | **z=−2.51 · p=0.012** |
| 반감기 중앙값 | 42봉 | 56봉 | |

원시 5% 로는 후보가 조금 앞서는데 BH 보정하면 뒤집혀 대조군이 유의하게 낫다.
두 지표가 반대를 가리킨다는 것 자체가 효과가 견고하지 않다는 뜻이다.

**왜 이렇게 되나.** 후보를 뽑을 때 상위 2개 고유포트폴리오를 회귀로 빼고 남은 **잔차** 상관으로
묶었다. 그런데 두 자산이 공적분한다는 건 보통 **공통 추세를 공유한다**는 뜻이다. 즉 후보 선정
단계에서 공적분을 만드는 성분을 일부러 제거한 셈이다. 같은 클러스터링이 잔차 평균회귀
(Avellaneda-Lee)에는 맞고 고전적 페어 공적분에는 반대로 작용한다.

**팩터를 안 빼면 되는가 — 안 된다.** `n_factors=0` 으로 원 수익률 상관에 묶어보니 기각률은
올라가는데(15.6% vs 10.7%) 군 하나가 449종목 중 **272개(60%)** 를 삼켜 내부쌍이 전체의 36.7%가
된다. 클러스터링이 아무 선택을 안 하는 상태이고, 대조군은 남은 주변부 종목 위주가 되어
비교 자체가 성립하지 않는다. 크립토 공적분이 대체로 **시장 공통 추세에서 나온다**는 정황이고,
그런 공적분은 상대 베타 드리프트일 뿐 차익거래 알파가 아니다.

### 1. `pairs.csv` — 공적분 검정에 넘길 후보 목록 (2,583행)

**이걸 제일 먼저 보면 된다.** 잔차상관 내림차순으로 정렬돼 있다.

| 열 | 형 | 뜻 |
|---|---|---|
| `a` `b` | str | 두 다리의 base 심볼. `a` 가 알파벳 앞이라는 것 말고 순서에 의미는 없다 |
| `cluster` | int | 속한 군 번호 (1~160). `clusters.csv` 의 같은 열과 이어진다 |
| `cluster_size` | int | 그 군의 종목 수 (1~29). 바스켓을 짜려면 3 이상이어야 한다 |
| `resid_corr` | float | **잔차** 상관. 0.09~0.40 범위. 아래 ⚠ 참고 |
| `adv_usd_min` | float | 두 다리 중 **작은 쪽**의 일 거래대금(USD). 중앙값 348만 달러 |
| `spread_max` | float | 두 다리 중 **큰 쪽**의 추정 스프레드(비율). 아래 ⚠ 참고 |
| `vol_a` `vol_b` | float | 각 다리의 연율 변동성 (0.6 = 60%) |
| `wash_z_max` | float | 두 다리 중 큰 쪽. 클수록 "거래대금 대비 안 움직임" |
| `same_asset_flag` | bool | True 6쌍. **검정 전에 눈으로 볼 것** |

**왜 min/max 로 접었나** — 쌍을 실제로 돌릴 때 유동성과 비용을 결정하는 건 항상 **나쁜 쪽
다리**다. BTC 와 무명코인을 페어로 묶으면 그 쌍의 체결 난이도는 무명코인이 정한다.
그래서 각 다리 값을 따로 싣지 않고 제약이 되는 쪽으로 접었다. 다리별 원값이 필요하면
`clusters.csv` 에서 `base` 로 조인하면 된다.

⚠ **`resid_corr` 는 원 가격 상관이 아니다.** 시장 모드(상위 2개 고유포트폴리오)를 제거한
뒤의 상관이라 훨씬 낮게 나온다. 0.40 이면 크립토 잔차 기준으로는 매우 높은 값이다.
원 가격 상관과 비교하지 말 것 — 그건 0.8~0.9 가 예사고 전부 BTC 베타다.

⚠ **`spread_max` 는 절대값을 믿지 말고 순위로만 써라.** Corwin-Schultz 추정치인데
1시간봉에서는 봉 내부 변동성이 스프레드를 압도해 10배 넘게 과대추정한다
(BTC 추정 9.7bp vs 실제 호가차 0.5~1bp). 종목 간 비교는 유효하다.

## 선정 과정

### 0단계 — 창을 자르고, 그 창을 완주한 종목만

180일 창, 관측률 95% 이상.

전 기간에 걸쳐 살아남은 종목만 고르면 **애써 포함시킨 상장폐지 종목이 전부 탈락한다.**
그러면 생존편향이 되살아나 수익률이 부풀려진다. 그래서 창마다 생존자를 따로 뽑는다 —
2023년 상반기 창에는 이후 상폐된 4종목이, 2024년 하반기 창에는 21종목이 실제로 들어가 있다.

`pairs.csv` 는 최신 창(2026-02-07~08-06)의 결과라 상폐 종목이 없다. 과거 창의 후보가 필요하면
`crypto/cluster.py` 를 그 창으로 다시 돌리면 된다.

### 1단계 — 유동성·마찰 필터 (929 → 477종목)

| 조건 | 탈락 | 왜 거르나 |
|---|--:|---|
| 일 거래대금 < $1M | 282 | 체결이 안 되면 스프레드가 아무리 벌어져도 못 먹는다 |
| 연율 변동성 < 20% | 141 | 스테이블코인·페그 자산. 평균회귀가 아니라 그냥 안 움직인다 |
| 추정 스프레드 > 0.4% | 93 | 왕복 마찰이 기대 수익폭을 이미 넘는다 |
| `wash_z` > 2 | 13 | 거래대금 대비 가격이 비정상적으로 안 밀린다 |
| 무변동봉 > 35% | 5 | 거래대금은 찍히는데 가격이 안 움직인다 |

기준값은 전부 **창 시작 시점 정보로만** 계산한다. 전체 기간 유동성으로 거르면 lookahead 다.

**`wash_z` 가 무엇인가.** 거래량은 만들어낼 수 있어도 가격충격은 만들기 어렵다. 그래서
Amihud 비유동성(|수익률|/거래대금)을 거래대금에 회귀하고, 그 잔차가 음수로 큰 종목
= "이만큼 거래됐으면 이만큼은 밀려야 하는데 안 밀린 종목"을 표시한다.

⚠ **이걸 "워시트레이딩 증거"로 쓰면 안 된다.** 실제로 걸리는 것에는 자기거래 의심 종목뿐
아니라 XAUT·PAXG 같은 **페그 자산**과 마켓메이커가 지배하는 종목이 함께 들어온다.
평균회귀 페어북에서 빼고 싶은 건 어느 쪽이든 같아서 필터로는 유효하지만, 인용은 하지 말 것.

회귀에 2차항이 반드시 들어간다. 유동성은 규모에 초선형이라(호가가 깊어지고 마켓메이커가
늘어난다) 직선으로 맞추면 최상위가 통째로 "충격이 너무 작다"로 찍힌다 —
1차 적합에서 BTC z=2.41 · ETH 2.15 로 둘 다 탈락선을 넘었고, 2차항을 넣으니 −0.41 · −0.44 였다.

### 2단계 — 시장 모드 제거

상위 2개 **고유포트폴리오**를 회귀로 뺀 잔차를 쓴다(Avellaneda & Lee 2010 §2.2).

크립토는 PC1(사실상 BTC 베타)이 분산의 절반 가까이를 먹는다. 원 가격 상관으로 클러스터링하면
"다 같이 움직이는 900개 + 이상한 것들"이 나온다. 고유벡터를 구하기 전에 각 종목을 자기
변동성으로 나누는 게 중요하다 — 안 나누면 고변동 밈코인 몇 개가 PC1을 통째로 차지한다.

`resid_corr` 열이 이 잔차의 상관이다. 원 가격 상관보다 훨씬 낮게 나오는 게 정상이다.

### 3단계 — 잡음 고유값 제거

Marchenko-Pastur 상한 (1+√(N/T))² 아래 고유값은 정보가 아니라 표본잡음이다
(N=477 · T=4,320 이면 1.74). 이 대역을 눕히고 대각을 1로 재정규화한다.

이걸 빼면 클러스터가 창마다 다르게 나온다. 순수 난수 477×4,320 만으로도 |상관| 0.15 넘는
쌍이 수백 개 생기기 때문이다.

### 4단계 — 계층 클러스터링

거리 `d = √(2(1−ρ))` — 상관을 그냥 쓰지 않고 이 변환을 거치는 이유는 이게 진짜 거리 공리를
만족하기 때문이다(Mantegna 1999). average linkage, k=160.

### 5단계 — 클러스터 내부 쌍만 채택 (113,526 → 2,583)

## k=160 을 고른 근거

결과를 보고 고르면 그건 튜닝이 아니라 자기기만이라, 규칙을 먼저 정하고 적용했다.
**세 하한을 모두 통과한 k 중 표본밖 초과상관이 가장 큰 것.**

- 후보쌍 ≥ 300
- 3인 이상 클러스터에 남은 종목 비율 ≥ 0.60 (바스켓 최소 인원)
- **최악의 창에서의 ARI ≥ 0.30** — 평균이 아니라 최악

## 이 표를 쓸 때 반드시 할 것

**① 다중검정 보정.** 2,583쌍을 5% 유의수준으로 검정하면 관계가 전혀 없어도 129쌍이
"유의"하게 나온다. Benjamini-Hochberg FDR 을 걸어라.

**② `same_asset_flag` 6쌍 확인.** 같은 자산의 배수 티커나 같은 프로젝트의 토큰 둘이
상관 상위를 차지한다. 이건 통계적 차익거래가 아니라 상환·단위 아비트라지다 —
공적분이 자명하게 성립하고 스프레드는 비용 밑이라 못 먹는다.

| a | b | resid_corr | 판단 |
|---|---|--:|---|
| LAYER | SOLAYER | 0.377 | 같은 프로젝트 토큰 둘 → 빼는 게 안전 |
| 1000NEIROCTO | NEIRO | 0.372 | 확인 필요 (별개 NEIRO 토큰일 수 있음) |
| 1000SHIB | SHIB1000 | 0.365 | **같은 자산, 표기만 다름 → 반드시 제외** |
| PUMP | PUMPFUN | 0.363 | 같은 프로젝트 → 빼는 게 안전 |
| 1000TURBO | TURBO | 0.353 | **같은 자산 → 반드시 제외** |
| 1MBABYDOGE | DOGE | 0.095 | **오탐** — BABYDOGE 와 DOGE 는 별개 코인. 남겨도 됨 |

마지막 행이 이 플래그를 자동 제외로 쓰면 안 되는 이유다(`1MBABYDOGE` 안에 `DOGE` 가
들어 있어서 문자열로 걸렸다). 눈으로 보고 빼라.

**③ 표본 밖에서 다시 검정.** 이 표는 최근 180일로 만들었다. 후보를 추린 창과 백테스트하는
창이 겹치면 그건 검증이 아니다.

**③-b 반감기 2봉 미만은 버려라.** 같은 자산이거나 마이크로구조 노이즈다(위 검증 절 참고).

**④ 비용을 먼저 정하고 시작.** 참고로 같은 데이터로 잔차 평균회귀 롱숏을 3년 워크포워드로
돌려본 결과, 거래당 총이익이 5.84bp(t=2.03)였다. 바이낸스 테이커 왕복이 10bp 라
**총이익이 유의해도 순이익은 유의하지 않았다.** 스프레드가 벌어지는 쌍을 찾는 것보다
비용을 넘길 만큼 크게 벌어지는 쌍을 찾는 게 어렵다.

페어는 다리가 둘이라 **왕복비용이 수수료의 4배**(2다리 × 진입·청산 2회)다. 테이커라면
최소 20bp 에서 시작한다. 문턱을 잡을 때 이걸 빼먹지 말 것.

**⑤ 기대 반전폭을 문턱으로 쓰지 마라.** OU 평형 표준편차 σ_eq 로 기대 수익을 추정해
비용과 비교하는 방식을 3년 6,565거래로 검증했는데, 기대-실현 상관이 **−0.007** 이었다.
기대 5분위 [47·71·96·133·296]bp 에 대해 실현이 [0.8·5.7·7.3·4.2·11.1]bp 로 단조도 아니고
분위별 t 가 전부 1.4 미만이다. σ_eq 는 잔차가 *끝까지* 되돌아갈 때의 폭인데 실제로는
68%가 시간 초과로 잘리므로, σ_eq 가 크다는 건 반전폭이 크다가 아니라 **변동성이 크다**는 뜻이다.

## 이 표에 없는 것

- **공적분 검정** — 상관과 공적분은 다른 물건이다. 여기까지가 후보 선정이고, 검정은 다음 단계.
- **헤지비율** — 공적분 회귀에서 나온다.
- **자금조달료(funding)** — 원본 데이터에 없다. 달러중립이면 상당 부분 상쇄되지만 0 은 아니다.
- **종목별 실거래비용** — 호가창 데이터가 필요하다. OHLCV 로는 원리상 안 나온다.
  `spread_max` 는 Corwin-Schultz 추정치인데 **1시간봉에서는 10배 넘게 과대추정한다**
  (BTC 추정 9.7bp vs 실제 호가차 0.5~1bp). 절대값이 아니라 **순위**로만 써라.
