# ArcTrade

**AI가 투자 전략을 제안하고, 실제 모델 학습과 백테스트를 반복해 운용 후보를 찾는 투자 연구 플랫폼입니다.**

한국주식·미국주식·크립토·타임폴리오를 한곳에서 연구합니다. 기본 연구 주제는 **인공지능 학습을 이용한 투자**입니다. 어떤 데이터를 얼마나 학습할지, 어떤 모델을 쓸지, 언제 사고팔지까지 하나의 전략으로 묶어 실험합니다. 로컬 AI의 제안에 유전 알고리즘의 교차·변이를 결합해 사용자가 멈출 때까지 탐색을 이어갑니다.

[서비스 열기](https://arctrade.ai-ve.uk)

## 연구가 진행되는 방식

1. **입력 준비**: 보유 시세를 확인하고 평가 기간에 필요한 거래일과 종목 자료를 준비합니다.
2. **전략 생성**: AI가 연구 방향과 후보 설정을 제안합니다. 완료된 후보의 OS 성과를 보고 부모 전략을 고르고 설정을 교차·변이합니다.
3. **실제 학습**: 후보마다 모델을 학습합니다. 각 시점에 알 수 있었던 정보만 사용해 순차적으로 예측합니다.
4. **백테스트**: 예측과 매수·매도 규칙을 계좌 장부로 계산하고 비용을 반영합니다. 성과는 IS·OS·ROS로 나누어 기록합니다.
5. **비교와 반복**: OS 수익률과 손실 개월 수로 파레토 후보를 찾고 다음 실험을 만듭니다.
6. **선택적 적용**: 사용자가 전략을 적용하거나 자동 적용을 켜면 해당 모델을 재학습하고 검증한 뒤 지원되는 페이퍼 계좌에 연결합니다.

전략을 제안하는 언어 모델과 수익률을 예측하는 투자 모델은 역할이 다릅니다. 언어 모델은 허용된 설정을 제안하며, 성과는 별도의 학습·백테스트 엔진이 계산합니다. 언어 모델이 생성한 임의의 코드는 실행하지 않습니다.

연구는 정해진 횟수 없이 반복합니다. 각 연구소에서 중단하면 실행 중인 실험은 마무리하고 새 실험은 시작하지 않습니다. 재시작 시 설정과 대기열을 복구하며, 자료나 자원이 부족하면 대기합니다.

## 무엇을 탐색하나요?

| 구분 | 현재 탐색 범위 |
|---|---|
| 모델 | Ridge, ExtraTrees, HistGradientBoosting, MLP, Residual MLP, LSTM, GRU, TCN, Transformer |
| 학습 조건 | 학습에 사용할 과거 일수, 시퀀스 길이, 모델 크기, 에폭, 배치 크기, 학습률, 정규화, 트리 깊이, 시드 |
| 입력 필드 | 시가·고가·저가·종가·거래량에서 계산한 수익률, 가격 범위, 추세, 변동성, 거래량 변화·순위 등 |
| 학습 목표 | 수익률, 위험을 조정한 수익률, 상승·하락 방향 |
| 매수·비중 | 상위 종목, 양수 예측, 상위 분위 선택과 동일 비중·변동성 역수·예측 점수 배분 |
| 매도·운용 | 보유기간, 리밸런싱, 신호 이탈, 손절·익절, 종목별 비중, 총 노출, 재학습 주기 |

실제 허용값은 [`autofolio/learning.py`](autofolio/learning.py)의 `domains()`에서 관리합니다. **평가 기간은 탐색 파라미터가 아닙니다.** 모델이 학습에 참고하는 과거 기간과 고정된 성과 평가 구간을 구분합니다.

신경망은 `compact`와 `large` 설정을 탐색합니다. 모델 종류와 크기를 번갈아 제안해 빨리 끝나는 모델만 반복되지 않도록 합니다. 학습 파라미터 수, 표본 수, 에폭 진행, 손실, 소요 시간을 기록합니다. 실험 시간은 모델·입력 크기·재학습 횟수에 따라 달라집니다.

현재 기본 연구 엔진은 **일봉 OHLCV 시계열**을 사용합니다. 데이터셋 탭에 뉴스·공시·분봉이 표시된다고 해서 모두 학습 입력으로 사용되는 것은 아닙니다. 뉴스 활동량은 필요한 수집 이력이 확보된 경우에만 사용할 수 있으며, 공시·차트 이미지·뉴스 텍스트를 함께 학습하는 멀티모달 모델은 아직 기본 탐색에 포함하지 않습니다.

## 평가 기준

한국 날짜 기준 **어제까지의 최근 36개월**을 다음과 같이 나눕니다.

| 구간 | 길이 | 용도 |
|---|---:|---|
| IS | 24개월 | 학습·개발 구간의 성과 확인 |
| OS | 9개월 | 후보 선발, 실험 지도, 순위, 파레토 판단 |
| ROS | 3개월 | 최근 구간의 최종 성과 점검 |

부모 전략 선택과 자동 적용 후보 판단에는 **OS 성과만** 사용합니다. ROS 성과는 다음 전략 제안이나 튜닝에 넣지 않으며, ROS 구간 중에는 모델을 재학습하지 않습니다.

학습과 예측은 시간순으로 진행합니다. 재학습 기준일 전에 결과가 확정된 라벨만 학습하며, 신경망 내부 검증도 시간순으로 나누고 경계를 넘어가는 라벨을 제외합니다. IS 구간의 초기 예측에는 평가 시작 전 자료가 필요하므로 입력에는 학습 준비 기간도 포함됩니다.

날짜가 바뀌면 평가 구간도 하루씩 이동합니다. 아직 시작하지 않은 후보는 새 구간으로 옮기고, 실행 중인 실험은 시작 시점의 기간·입력·코드 버전을 유지합니다. 이전 결과도 당시 기간으로 조회할 수 있으며, 서로 다른 평가 달력의 결과를 하나의 파레토 집단으로 합치지 않습니다.

주식은 시장 거래일, 크립토는 UTC 기준 완료된 날짜의 자료를 확인합니다. 장이 끝나지 않았거나 필요한 날짜의 자료가 부족하면 평가를 대기시킵니다. 손실 개월 수는 평가 구간의 경계에 맞춘 월 단위 수익률로 계산합니다.

OS는 반복 탐색에 사용하므로 독립적인 최종 검증 성과가 아닙니다. 과거 개발 과정에서 ROS에 해당하는 자료를 본 이력도 있을 수 있어, 구간 분리만으로 독립 검증을 인증하지 않습니다.

## 화면 구성

| 탭 | 주요 기능 |
|---|---|
| 금일 시황 | 로그인 없이 공개. 코스피·S&P 500·BTC 차트, 최근 뉴스, 조건을 충족한 새 연구 후보 |
| 데이터셋 | 보유 자료 종류와 실제 시작·종료일. 같은 자산의 현재·과거 분봉은 통합 표시 |
| 한국주식 | 일반 모드 분봉 페이퍼매매 / 관리자 연구소 |
| 미국주식 | 페이퍼매매 / 연구소 |
| 크립토 | 페이퍼매매 / 연구소 |
| 타임폴리오 | 모의매매 / 연구소 |

연구소에는 실험 지도, 10개씩 넘겨 보는 리더보드, 자원 설정, 전략 입력, 학습 진행 로그가 있습니다. 전략 상세에서는 IS·OS·ROS 성과와 수익률 곡선, 매매 기록, 학습 조건을 확인합니다. 매매 화면에는 계좌 수익률, 보유 종목, 거래 기록, 연결 상태를 표시합니다.

실험 지도는 선택한 위험 지표가 왼쪽으로 갈수록 작아지도록 배치합니다. 새 결과가 도착하면 지도에 추가되며, 실제 적용 장부가 확인된 전략은 **다이아몬드**로 표시합니다. 논문 기반 크립토 장부는 AutoCrypto로 분리했습니다. ArcTrade는 최근 동일 평가 집단에서 수익률·샤프 × MDD·손실월의 네 조합으로 구한 현재 파레토 전략을 모두 표시합니다. 탈락한 전략의 기록은 보존하고 공개 운용 목록과 추가 갱신에서는 제외합니다.

금일 시황은 공개 시장 차트와 최근 뉴스, 현재 파레토 후보를 표시합니다. 관리자 모드는 데이터셋과 네 시장 연구소만 제공하며 시장 서브탭과 한투 매매 기능은 제거했습니다. 이 목록은 탐색 필터이며 통계적 유의성 검정 결과는 아닙니다.

## 전략 적용과 매매 연결

자체 페이퍼매매는 외부 주문 API 없이 전략별 계좌를 모의합니다. 한국주식은 실제 관측 분봉으로 별도 전환 모델을 시간순 검증하고 다음 관측 종가에 체결합니다. 일봉 검증 통과를 분봉 성과 인증으로 승계하지 않으며, 신경망 시퀀스·OHLC 입력 미연결 후보는 차단 상태를 표시합니다. 미국주식·크립토·타임폴리오 연구 전략별 페이퍼는 기존 일봉 실행 정책을 유지하며 실시간 관측 평가를 따로 기록합니다. 타임폴리오 탭에는 실제 13회 대회 계좌의 공개 관측도 별도 표시합니다. 적용 이전의 백테스트 거래를 실제 운용 기록에 합치지 않습니다.

실험 중 학습한 가중치는 디스크에 보관하지 않습니다. 결과, 거래 장부, 학습 증거와 재현 명세를 남기고, 적용할 전략이 정해지면 보존된 입력·코드·시드·설정으로 명세의 최종 학습 기준일 모델을 다시 학습합니다. 여러 시점의 백테스트 모델 중 하나를 그대로 복사하는 방식은 아닙니다.

명세에는 데이터 해시, 입력 필드, 학습·평가 경계, 패키지 버전, 코드 해시를 기록합니다. 재학습 시 이를 검사하며 적용 모델의 가중치만 유지합니다. 후속 모델로 교체하면 이전 적용 모델의 가중치를 정리합니다. 입력 스냅샷과 버전별 코드는 실험들이 공유합니다.

각 연구소의 **새 파레토 전략 자동 적용**은 기본적으로 꺼져 있습니다. 켠 뒤 새로 발견된 현재 평가 구간의 OS 파레토 후보 중 수익률이 가장 높은 전략을 고르고, 동률이면 손실월이 적은 전략을 선택합니다. 재학습과 검증을 마칠 때까지 기존 운용 모델을 유지합니다. 토글을 끄면 대기 작업을 취소하고 진행 중인 자동 재학습의 최종 적용도 차단합니다.

| 연결 | 현재 범위 |
|---|---|
| 한국·미국·크립토 자체 페이퍼 | 새 학습 전략의 수동·자동 적용 지원 |
| 한국투자증권 실매매 | 정지 상태. 주문 및 전략 적용 차단 |
| 타임폴리오 | 13회 계좌 조회·모델 재학습·파레토 자동 적용. 거래시간에 사이트의 종목·섹터 검사를 거쳐 모의 주문 |
| 기존 크립토 논문 모델 | 기존 운용 장부 표시. 새 전략 적용 시 관리자의 자체 페이퍼 계좌로 전환 |

타임폴리오 연구는 보유기간·비용·업종·소형주·노출·회전율 제약을 보수적으로 근사합니다. 과거 시점의 종목 지정·업종·시가총액 규칙 검증이 완료되지 않아 대회 적합성을 인증하지 않습니다. 실제 운용은 이 과거 인증과 별도로 주문마다 검사합니다. 현재 시가총액 분류를 확인하기 전에는 전체 보유를 소형주로 간주해 총노출을 30% 이하로 제한합니다. 따라서 백테스트 수익률과 실제 모의계좌 수익률은 다를 수 있습니다. 미체결 주문이 있으면 기다리고, 접수 여부가 불명확하면 추가 주문을 중지합니다. 기존 크립토 모델도 모델별 관측 기간과 비용 반영 범위가 다르며, 화면에 원본 장부의 기준을 표시합니다.

## 공개 화면과 관리자

로그인 없이 한국주식·미국주식·크립토의 페이퍼 성과를 볼 수 있습니다. 공개 API는 관리자 소유 장부의 허용된 성과·보유·체결 필드만 읽으며 계좌 연결 정보, 연구 설정, 모델 경로를 내보내지 않습니다. 회원가입과 일반 회원 로그인은 종료했습니다. 기존 관리자 계정의 아이디·비밀번호는 유지하며 연구소·계좌 연결·자원 설정은 관리자만 사용합니다.

화면은 AutoCrypto의 거래 터미널 구조를 사용합니다. 중앙에는 전략 수익률을 분·시간·일 단위로 표시합니다. 분·시간 차트에는 실제 관측한 평가액만 사용하며 일봉이나 4시간 장부를 보간하지 않습니다. 미국주식은 현재 장중 관측 시세가 연결되지 않아 일별 장부만 표시합니다. 한국주식은 별도 분봉 Ridge 모델의 신호로 모의매매합니다. 원본에 장중 OHLC가 없어 신호를 기록한 뒤 새로 관측된 분별 종가로 체결하며, 최소 보유 30분·수수료·슬리피지·분 거래량 제한을 적용합니다. 기존 현금·보유·체결 이력은 유지합니다. 분봉 모델은 시간 분리 학습 검사를 거친 전진 검증 단계이며 기존 일봉 OS 인증을 승계하지 않습니다. 시세의 기준 시각과 지연 여부를 함께 표시합니다.

연구소 그래프는 Y축을 OS 수익률·샤프, X축을 MDD·손실 개월 수에서 선택합니다. MDD는 손실 폭의 절댓값이 작을수록 좋습니다. 축을 바꾸면 표시하는 파레토 경계도 다시 계산하며 자동 적용의 고정된 선발 기준은 유지합니다.

## 거래 표본 검증

OS 9개월에 다음 조건을 모두 충족해야 리더보드, 부모 전략 선택, 자동 적용, 수동 재학습 후보가 됩니다. 모든 계좌 시작점에 같은 기준을 적용합니다.

- 청산 완료 포지션 20건 이상. 분할 체결은 하나의 포지션으로 계산합니다.
- 청산이 발생한 날짜 10일 이상.
- 평가액의 1% 이상을 투자한 날짜 30일 이상이며 OS 거래일의 10% 이상.
- 실제 투자한 달 6개월 이상.
- 유효한 거래·잔고 기록과 유한한 수익률·MDD·샤프.

이는 과소 표본·현금 대기를 거르는 운영 기준이며 통계적 유의성 인증이 아닙니다. ROS 거래나 성과로 이 조건을 맞추지 않습니다. 이전 결과는 재색인해 같은 검사를 적용하고, 탈락한 실험의 상세 기록은 유지합니다. 크립토 샤프는 365일, 주식은 252일로 연율화합니다. 반복 탐색에서 발생하는 과적합 가능성은 별도 검증 대상입니다. [백테스트 과적합 연구](https://carmamaths.org/jon/backtest2.pdf)를 참고했습니다.

`arctrade-minute-paper.timer`는 30초마다 국장 분봉 신호·체결·평가를 점검합니다. 매일 별도의 분봉 모델을 학습하고 신호 이후의 관측 시세만 체결에 사용합니다. `arctrade-observations.service`는 연구 대기열과 별도로 1분마다 평가액을 관측합니다. `arctrade-paper.timer`는 일봉 장부와 타임폴리오 실행을 별도로 점검해 장시간 모델 학습 때문에 매매 갱신이 대기하는 문제를 막습니다. 기존 시세 수집기와 HYFE 크립토 운용 작업은 계속 같은 원본을 사용합니다.

## 데이터 범위와 재현 조건

연구는 보유한 유니버스에서 자료 조건을 충족하는 종목을 사용합니다. 시장 전체의 과거 상장·상장폐지 종목을 완전히 복원한 데이터셋은 아니므로 생존 편향과 수집 대상 선택 편향이 있습니다. 기업행사, 거래 가능 상태, 체결 가능성에도 추가 검증이 필요합니다.

주식 입력은 학술제 검증 시세의 종목 근거와 자동 갱신하는 확장 일봉을 사용합니다. 한국·미국 페이퍼매매도 같은 확장 일봉을 읽으며, 모델 교체 시 기존 장부를 유지합니다. 크립토는 보유 분봉을 공유 일봉으로 집계하고 잘못된 봉을 제외합니다. 필요한 날짜가 부족하면 같은 거래소·종목의 확정 일봉을 대조해 연구 입력에 보완하고 그 근거를 보관합니다. 수집 원본은 수정하지 않습니다.

원본 종목 검증 파일이 없으면 해시가 일치하는 과거 연구 입력에서 당시의 종목 근거를 복구합니다. 미래 자료, 해시가 바뀐 파일, 검증에 실패한 입력은 사용하지 않습니다. 복구 후에도 시세·거래일·최소 종목 수 검사를 다시 수행하며, 신규 종목을 임의로 검증된 종목에 추가하지 않습니다.

크립토 시세 수집기는 분봉을 약 10분마다 파일에 저장합니다. 따라서 1분마다 평가액을 관측해도 시세 자체에는 지연이 있을 수 있으며 화면에 원본 시세의 기준 시각을 표시합니다.

데이터셋 화면의 최소·최대일은 보유 자료의 합집합 범위입니다. 모든 종목에 그 기간의 연속 자료가 있다는 뜻은 아닙니다. 실제 평가 가능 여부는 별도의 입력 검사에서 판단합니다.

저장소에는 소스와 테스트를 보관합니다. **운영 데이터, 학습 입력, 계좌 정보, 모델 가중치, 비밀 설정은 포함하지 않습니다.** 현재 데이터 로더는 운영 호스트의 공유 라이브러리와 보관 경로를 참조하므로, 다른 환경에서 실행하려면 해당 데이터와 경로를 준비해야 합니다.

## 실행과 개발

운영 환경은 Python 3.12와 Linux/systemd입니다. 새 환경에서는 별도의 가상환경을 만들고 의존성을 설치합니다.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
```

실행 전 준비할 항목은 다음과 같습니다.

- `autofolio/config.py`, `autofolio/research.py`와 입력 로더가 참조하는 데이터·공유 라이브러리 경로
- 쓰기 가능한 연구 상태·결과 경로와 비밀 저장소 연결
- 최초 관리자 계정: `autofolio.auth.bootstrap_admin()`으로 로컬에서 생성
- 로컬 AI 연결 및 연구소 활성화 설정

웹과 워커는 각각 별도 프로세스로 실행합니다.

```sh
# 웹
python3 -m uvicorn autofolio.app:app --host 127.0.0.1 --port 8997
```

```sh
# 연구 워커
python3 -m autofolio.worker
```

```sh
# 테스트
python3 -m pytest tests -q
```

직접 실행한 워커에는 운영 서비스의 cgroup 한도가 자동으로 붙지 않습니다. 상시 운영 시 [`deploy/autofolio-worker.service`](deploy/autofolio-worker.service)를 환경에 맞춰 사용합니다. 운영 서비스의 `server.app:app` 진입점도 같은 웹 앱을 연결합니다.

연구 제어 설정은 `labs_v2_enabled`, `lab_enabled_<market>`, `neural_research_enabled`, `research_campaign_owner`입니다. 한투 실매매 정지와 타임폴리오 적용 제한은 연구소 활성화와 별도로 유지됩니다.
